# Wonder-Box Pong

A simple, responsive Pong game built with plain HTML, CSS, and JavaScript.

## Play

Open `index.html` in a modern web browser. No build tools or dependencies are required.

- Move the left paddle with your mouse or the **↑ / ↓** arrow keys.
- Play against the computer-controlled right paddle.
- Press **Space** to pause or resume.
- Select **New game** to reset the scoreboard and serve again.

The game includes wall and paddle collision detection, bouncing ball physics, and a live scoreboard.
